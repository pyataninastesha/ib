# Веб‑приложение «Кейтеринг»

Проект для оформления заказов и подготовки банкетов: пользователи выбирают блюда из меню, собирают корзину, оформляют заказ или создают заявку на банкет. Менеджер управляет складом, меню и заявками, формирует отчёты.

## Роли

- **Клиент** — просматривает меню, добавляет блюда в корзину, оформляет заказы, создаёт заявки на банкет.
- **Менеджер** — обрабатывает заявки на банкет, следит за складом, смотрит отчёты.
- **Администратор** — доступ к админ‑панели Django.

## Быстрый запуск (локально)

В корне проекта есть файл `start.py`, который автоматически:

- создаёт виртуальное окружение `.venv` (если его нет);
- устанавливает зависимости (если изменился `requirements.txt`);
- применяет миграции;
- загружает меню из `data/menu_seed.json` командой `seed_menu --reset`;
- запускает сервер.

### Запуск

```bash
python start.py
```

Если порт `8000` занят, сервер стартует на следующем свободном.

## Полезные ссылки

- Главная: `http://127.0.0.1:8000/`
- Меню: `http://127.0.0.1:8000/menu/`
- Вход: `http://127.0.0.1:8000/login/`

## Команды вручную (если нужно)

```bash
python manage.py makemigrations
python manage.py migrate
python manage.py seed_menu --reset
python manage.py createsuperuser
python manage.py runserver
```

## Примечания

- Для локального запуска `SECRET_KEY` автоматически создаётся и сохраняется в файл `.local_secret_key` (если переменная окружения не задана).
- На хостинге/в продакшене задавайте `SECRET_KEY` через переменные окружения.
