КРАТКОЕ ОПИСАНИЕ
1. Суть проекта:
Разработано полнофункциональное веб-приложение для комплексной автоматизации учета и организации питания в школьной столовой. Система заменяет бумажный документооборот и ручные процессы, предоставляя удобный цифровой интерфейс для всех участников.

2. Решаемая проблема:
Устранение неэффективности ручного учета заказов и платежей, сложностей в планировании закупок для столовой, отсутствия прозрачности для родителей и администрации. Система централизует и упорядочивает весь процесс питания.

3. Ключевая функциональность (по ролям):

· Для ученика: Просмотр меню дня, онлайн-выбор завтраков, обедов и напитков, предзаказ питания по абонементу, пополнение кошелька, отслеживание истории заказов и расходов.
· Для повара: Доступ к актуальным данным о количестве заказов по каждому блюду и заказов по абонементам, отслеживание количества продуктов и готовых блюд, формирование запросов для закупки к администратору 
· Для администратора: просмотр статистики оплат и посещаемости, согласование заявок на закупки, формирование отчетов по питанию и затратам, отслеживание финансов.

4. Технологический стек:

Проект написан на языке Python с использованием Django, HTML, CSS, JavaScript, Bootstrap и SQLite

5. Достигнутый результат:
Цель проекта — создание удобного и качественного инструмента — успешно достигнута. Реализована трехролевая модель (ученик, повар, администратор) с изолированным функционалом, что обеспечивает:

Удобство: Онлайн-заказ избавляет от очередей и наличных расчетов.
 Эффективность: Столовая оптимизирует логистику и расход продуктов.
Контроль: Администрация получает инструмент для полного управления процессом и аналитики.
Прозрачность: Видна статистика о купленных блюдах и напитках.


ИНСТРУКЦИЯ ПО ЗАПУСКУ 
- Создать и активировать виртуальное окружение:
python -m venv venv
venv\Scripts\activate

-Установить зависимости:
pip install -r requirements.txt

-Применить миграции базы данных:
python manage.py migrate

-Запустить сервер:
python manage.py runserver

Проект будет доступен по адресу: http://127.0.0.1:8000/
