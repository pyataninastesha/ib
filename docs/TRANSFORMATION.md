# EcoFood Platform — что изменено по сравнению с проектом «столовая»

## Новая концепция
Проект переосмыслен как экологическая платформа учета пищевых ресурсов для конкретного заведения (организации).
Столовая/кафе/школа — это лишь кейсы применения.

## Ключевое функциональное изменение
### 1) Организация (заведение)
Добавлена модель `core.Organization`:
- тип заведения
- цели
- среднее порций/день
- код подключения (join_code)

### 2) Пользователь привязан к организации
Поле `users.User.organization`.

### 3) Регистрация стала организационной
- Eco-менеджер (роль admin) создаёт организацию при регистрации.
- Сотрудники/участники подключаются по `join_code`.

### 4) Данные теперь могут быть разделены по организациям
В основные сущности добавлено поле organization:
- `core.PurchaseRequest`
- `users.Subscription`, `users.MealRequest`, `users.MealReceipt`
- `menu.Product`, `menu.DailyMenu` (+ уникальность по (organization, date))

### 5) Добавлен Eco Dashboard
Новая страница: `/eco/dashboard/`
Показывает eco-метрики по организации:
- выдано / потреблено / риск отходов за 7 дней
- закупки в работе
- склад: позиции в зоне риска (низкие остатки)
